# 多闲鱼账号

> 个人使用：一个控制台，管理多个**真实闲鱼账号**；每个账号一个值守实例。

## 1. 形态

```text
控制台 :8787（唯一入口）
  ├─ 账号 A（闲鱼账号 1）→ data/              → 8801（内部）
  ├─ 账号 B（闲鱼账号 2）→ data/shops/acct_2/ → 8802（内部）
  └─ 账号 C（闲鱼账号 3）→ data/shops/acct_3/ → 8803（内部）
```

- 每个账号独立 SQLite、Cookie/Token、WebSocket、值守 Agent；
- 控制台只负责启动/守护/代理，不共享买家和订单数据；
- 控制台只监听 `127.0.0.1`，个人本机使用，不需要登录；
- 没有本地“店铺注册”，账号身份来自闲鱼扫码登录。

## 2. 启动

```powershell
.\run.ps1
```

只需这一个入口，不再有单独的 `run-control.ps1`。

## 3. 添加真实闲鱼账号

1. 控制台「添加闲鱼账号」填一个本地名称（如“主号”“小号”）；
2. 点“添加并启动”，控制台自动分配端口、数据目录和进程；
3. 点该账号的「扫码登录」；
4. 用真实闲鱼 App 扫码；
5. 登录成功后自动同步商品；
6. 工作台选择该账号，即可看买家会话、人工回复、给小二下指令。

数据目录：

```text
default       data/
acct_2        data/shops/acct_2/
acct_3        data/shops/acct_3/
```

账号 ID 只允许字母、数字、下划线、短横线；非法字符会被替换，避免路径穿越。

## 4. 控制台能做什么

- **账号管理**：添加、启动、停止、重启、扫码登录、同步商品；
- **统一工作台**：跨账号买家会话、人工回复、接管/恢复 AI；
- **店主指令**：选具体账号，对小二说“下架 xxx / 改价 199 / 发布 …”；
- **确认卡**：发布/改价等待确认项可直接确认或取消；
- **排期**：按账号做确定性抖动，把擦亮/日报时间写回各账号 patrol，避免同时打平台；
- **汇总**：账号运行状态、未处理告警、当天指标。

## 5. 备份

停控制台和对应账号后，复制目录：

```text
data/                                 默认账号
data/shops/acct_2/                    账号 2
data/control/accounts.json            账号实例注册表
data/control/logs/                    各账号运行日志
```

## 6. 边界

- 一个实例同一时间只连一个 active 闲鱼账号；
- 多账号同时在线 = 多个实例同时运行，不是单进程多开；
- 账号需逐个扫码，平台登录态过期要重新扫码；
- 控制台不是 Windows 服务，机器重启后需重新启动；
- 多账号操作仍有平台合规风险，账号资质和经营行为需自行评估。
